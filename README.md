# SHIVAM Wholesale (React Web Rewrite)

This is a full-stack React web application that serves as the new portal for the SHIVAM Wholesale app, completely rewritten from the original Android application into a client-side React App.

## Features
- **Admin Dashboard**: Create customer accounts and manage departmental packing (Imitation, Cosmetics, Hair Accessories) for live orders.
- **Catalog Navigation**: Browse wholesale designs grouped by Category and Subcategory Folders.
- **Order Placement**: Customers can add items (options A, B, C, D) to their cart and checkout seamlessly.
- **Customer Authentication**: Customer login is based on Unique IDs generated by the Admin Dashboard.

## Development
This app is built using React, Vite, Tailwind CSS, and Zustand.

1. Install dependencies: `npm install`
2. Start dev server: `npm run dev`
3. Build for production: `npm run build`
